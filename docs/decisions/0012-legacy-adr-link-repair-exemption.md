# 0012 · 旧 ADR 能不能修链接

## 背景

/docs-sync 检查发现：ADR 0001–0005 里的 **15 条相对链接全部失效**（分布在 12 行），而规范 §3「旧 ADR 永不修改」使这类坏链在现行规则下**永远修不掉**。

forces：

- 规范 §3 的动机是**历史原貌不可改写**：决策的时效性只由新 ADR 的 `supersedes` 单向表达，「已被取代」靠扫描链计算、不回写旧文件。这条已经真实生效过一次 —— ADR 0007 后果段写的「`parser.c`（约 20 MB）随仓库提交」与仓库事实相反，更正落在 [../README.md](../README.md) ADR 清单说明段与 [../project.md](../project.md) 技术栈行，**0007 本体一字未改**（log 2026-10-28 13:35）。
- 这次的坏链不是决策内容错，是**路径前缀写错**：`docs/decisions/0001-…:12,14,27`、`0002-…:10,14,23`、`0003-…:10,12,22`、`0004-…:10,24`、`0005-…:22` 写的是 `../../分析/…`（0002 另有一条 `../../specs/…`），从 `docs/decisions/` 解析到仓库根的 `分析/`、`specs/` —— 两个目录都不存在（实测只有 `docs/分析/`、`docs/specs/`）。同一目录里的 ADR 0008–0011 用的是正确的 `../分析/…`，证明正确写法无争议。
- 规则内部已经打架：/docs-sync 的修复模式允许「修相对链接」，§3 却禁止改动旧 ADR 文件 → 检查项「链接有效性」在这 5 个文件上是**永久红**，每轮都要重新报告一遍。
- 坏链的实际代价是**证据链断裂**：ADR 的备选否决理由全部挂在 `分析/` 的实测文档上（例如 0003 引 `03-language-server.md` §4 证明对标产品对 `.std` 故意不跳），链接点不开，后来者就无法复核当初的判断。

备选：

- **E1 严格不可变，坏链永久保留**：规则最干净；代价是 5 份 ADR 的证据链长期失效，且 /docs-sync 的链接检查无法收敛 → 否。
- **E2 照 0007 的先例，只在索引与 log 登记「正确路径」，不改文件**：0007 登记的是**事实性错误**（需要一段更正文字去覆盖一段错误文字）；路径前缀错误没有可更正的语义，登记只会把 15 条噪音写进索引，链接照样点不开 → 否。
- **E3 把旧 ADR 重写或迁移到统一路径写法**：一次做干净；但重写正文正是 §3 要防的事（决策原话、备选措辞、当时的判断口径都会漂）→ 否。
- **E4 窄豁免（选定）**：只允许机械修复相对链接的路径，正文一字不动，改动逐条登记。

## 决策

旧 ADR 文件的不可变性开一个**唯一且可机械校验**的例外：允许把相对链接的**目标路径**改成正确路径（`../../X` → `../X` 这类前缀修正）；当链接文字与目标原本完全相同（拿路径当标签）时，允许把两者同步改成同一个修正后的路径。**除此以外的任何字节都不许改** —— 正文文字、结论、备选、日期、frontmatter（`adr`/`date`/`title`/`supersedes`）一律不动，且每次修复必须在 `log.md` 逐条登记改了哪个文件哪几行。

## 后果

- 正面：15 条证据链恢复可点，ADR 的决策语义与历史判断零改动；/docs-sync 的「链接有效性」检查从永久红变成可清；改动面小到可以用 diff 机械复核（只允许 `](…)` 内的字符串变化，或 `[X](X)` → `[Y](Y)` 的同步修正）。
- 负面（接受）：
  - 旧 ADR 不再是**字节级**不可变 —— 「git diff 里出现旧 ADR」不再自动等于违规，合规判定从「文件有没有被碰」变成「碰的内容是否在豁免范围内」，多了一层需要人判断的边界。
  - 豁免有被顺手滥用的空间（改链接之名改措辞）。收窄办法：豁免只覆盖路径字符串本身，任何措辞变化都算违规，由 log 登记 + diff 复核兜住。
- 明确**不在**豁免范围内（仍按 §3 与既有先例处理）：
  - 事实性错误的更正 → 照 0007 先例，落在 `docs/README.md` ADR 清单说明段与 `log.md`，旧文件不改；
  - 旧 ADR 里的**代码行号引用漂移**（如 0009 引 `server/src/parser.ts:118-125`，`countErrorNodes` 现已在 `:127`）→ 不修，只登记；要根治得改规范里「引用代码位置」的写法（改用符号名而非行号），那是另一次 conventions 变更；
  - 借修链接改标题文字、锚点、前后措辞 —— 一律禁止。
- 与既有 ADR 的关系：**不取代任何 ADR**。本 ADR 改的是 [../reference/conventions.md](../reference/conventions.md) §3/§4 的规则边界，已按 conventions 开头那句「修改本文属架构级变更」在 §3 补一条豁免说明并引用本 ADR。
- 落地边界：本次 15 条链接修复（分布在 12 行）由 /docs-sync 修复模式执行（ADR 0001–0005），改动清单逐条落 `log.md`；不产生新任务，不进 backlog。
